# iman_library
IMAN Library Mobile Application | Android, Flutter, Dart

-Developed a fully responsive Android e-commerce application using Flutter and Dart, specifically designed to resolve the mobile optimization issues of the existing web platform.
-Engineered a mobile-first user interface (UI) to replace legacy web views, significantly improving navigation and visual hierarchy for IMAN Shoppe users.
-Implemented real-time push notification features to alert users of events and specials, directly addressing the website's lack of immediate user engagement.
-Utilized Android Studio and VS Code to build a solution focused on increasing customer loyalty and retention through a seamless shopping experience.
